⚠️ Generic Assumption — Not a Direct Comparison
This estimate mirrors token volumes from the GitHub Copilot side and maps each model to a roughly equivalent Anthropic model by tier. It is intended only to generate a complete illustrative example and should not be used for vendor selection without independent analysis.
  • Copilot Anthropic models map directly to their Anthropic API equivalent
  • OpenAI/Google/Microsoft models are mapped by capability tier (lightweight → Haiku, versatile → Sonnet, powerful → Opus)
  • Model capabilities, context windows, quality, and latency differ — cost is not the only variable
  • Cache write costs are estimated using Anthropic's standard rate for all mapped models
